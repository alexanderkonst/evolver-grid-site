# Canonical Commercial Ledger v1

Every tool exchanges the same envelope:

- schema: evolver-commercial-ledger
- version: 1
- producer: icp-prospector, outreach-radar, or relationship-hub
- records: canonical person and commercial-state records
- outcomes: aggregated downstream results by ICP and originating search term

Identity preference: LinkedIn profile URN, then normalized email, then existing stable id.

Source attribution is first-touch and survives every merge. Commercial state is monotonic: later stages cannot be downgraded by an older import.

Tool 1 consumes outcomes to judge search terms by replies, calls and cash—not merely people found. Tool 2 enriches records with verified LinkedIn conversation state. Tool 3 enriches the same records with email, follow-up state and final commercial outcomes.
