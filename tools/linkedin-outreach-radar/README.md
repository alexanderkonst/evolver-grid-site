# LinkedIn Outreach Radar — Alexander Konstantinov

Tool 2 of the canonical commercial system. It imports Tool 1 records, reconciles them against real LinkedIn conversations, prevents duplicate outreach, and advances the same person through the funnel.

Run tests:

```bash
node tools/linkedin-outreach-radar/core.test.mjs
```

To activate, attach `artifact.html`, `core.mjs`, and `CLAUDE_HANDOFF.md` to a fresh Claude Cowork chat with Connect Safely enabled.
