# /products/vector fonts

Self-hosted woff2, Cyrillic + Latin subsets only, loaded by `src/pages/TheVector.css` and used only under `.vector-fonts` (the Vector page).

| Family | Role | Source |
|---|---|---|
| Forum | headings, hero title | Google Fonts, SIL OFL 1.1 |
| Alegreya (variable 400–700, normal + italic) | body | Google Fonts, SIL OFL 1.1 |
| Alegreya Sans SC (400, 500, 700) | eyebrows, labels, section numbers, CTA | Google Fonts, SIL OFL 1.1 |

Subsets are Google's `cyrillic` (U+0400–045F, U+0490–0491, U+04B0–04B1, U+2116) and `latin`, fetched from fonts.gstatic.com on 2026-11-18.
