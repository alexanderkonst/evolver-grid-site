## Confirmed teaching preferences

English explanations; natural standard Japanese pronunciation for taught material. Vivid Russian, Spanish, or English memory hooks when needed. Structural keys lead; familiar vocabulary is retrieved without pre-cueing. One challenge at a time, space for correction, no routine continue/pause questions. These are explicit preferences, not established causal learning benefits.
