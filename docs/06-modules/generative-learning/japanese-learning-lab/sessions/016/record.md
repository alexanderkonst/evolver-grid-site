Tutor had failed to teach the plain-form requirement before eliciting; after checking the Japan Foundation Irodori rule and supplying `ikemasu → ikeru`, learner built `ashita Kyōto ni ikeru to omoimasu`. This error is tutor-induced, not clean learner evidence.
