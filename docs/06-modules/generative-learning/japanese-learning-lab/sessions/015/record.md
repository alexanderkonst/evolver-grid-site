# Session 015 — October 26, 2026

Evidence: written turns and speech-recognition text. Japanese glyphs are dictation, not evidence of script literacy; pronunciation is unassessed. Russian elicitation, romaji feedback. Learner explicitly made the final opinion sentence the last task of the day.

## New keys and demonstrated work

- `V(dictionary) mae ni` (“before doing V”) introduced with the familiar base form `nomu`; learner built `Kyōto ni iku mae ni, watashi no tomodachi to hanashimasu` after several companion-role repairs (`ni`, `de`, then `wa` before `to`). He later independently transferred the key to `watashi no tomodachi to hanasu mae ni ocha o kaimasu`. This is the strongest local generation for the new key.
- Contrast with earlier `V-te kara` (“after doing V”): learner initially gave two independent actions and an extraneous `doko de`, then placed `kara` at sentence start. After a more specific `hanashite kara` cue, he built `watashi no tomodachi to hanashite kara Kyōto ni ikimasu`. The tutor then contrasted sequential `hanashite kara` with causal `kara`. For “I want to talk with a friend, so I will go to Kyoto,” learner first said `hanashimasu kara`; after a meaning-level cue and an explicit form table requested by the learner, he built `watashi no tomodachi to hanashitai desu kara Kyōto ni ikimasu`. Polite `desu kara` was accepted; speech-recognition punctuation was not treated as a spoken stop.
- Learner explicitly requested a small table of forms of `hanasu` because `hanashimasu`, `hanashitai`, `hanasemasu`, `hanashimasen`, `hanashimashita`, and `hanashite imasu` were becoming hard to distinguish. Tutor supplied it. This is a targeted requested aid, not a default conjugation-table curriculum.
- Opinion `to omoimasu` introduced with dictionary form `omou`, polite `omoimasu`, and a model with familiar `ikeru`. Learner built `kono ocha wa oishii to omoimasu` after replacing object `o` with topic `wa` and removing `desu` from inside the thought. Learner then built `kono ocha wa takakunai to omoimasu` after first using invalid adjective negation `takai-masen` and explicitly requesting a reminder of `takai → takakunai`. Final form correct with that model.
