# Japanese Learning Lab

## Four working documents

- [AI Tutor Master](AI-TUTOR-MASTER.md): complete teaching protocol.
- [Learner State](LEARNER-STATE.md): current evidence and next-session frontier.
- [Observations](OBSERVATIONS.md): hypotheses and small tests.
- [Blueprint](BLUEPRINT.md): operating loop and evidence standards.

Use the [Japanese Evolution Map](JAPANESE-EVOLUTION-MAP.md) alongside the master and learner state. It traces the spoken route from the starting point through C2 and gives worked module sequences, including the next lesson. The learner state records the latest evidence and current starting point.

For another skill, start from the [portable Skill Tutor Master](../AI-SKILL-TUTOR-MASTER.md). It carries the shared method. The language master adds target-language and language-pair teaching rules.

To continue in another chat, share the master, learner state, and relevant part of the map. Bring any session transcript back here for the record when needed. Cross-chat capture requires supplying that evidence.

Session 001 has selected evidence excerpts, not a complete raw transcript. Original source documents and historical setup files remain preserved. learner-model.json is a compatibility summary; LEARNER-STATE.md is authoritative. No software build is needed for this stage.

[Japanese Keybook](JAPANESE-KEYBOOK.md) collects short explanations and learner-built examples, linked to session evidence. Use it to revisit a key or see how it developed.
