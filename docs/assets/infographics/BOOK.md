## Content

### III.01 · Three Readinesses Multiply
- Context (eyebrow): Choosing a client · Readiness
- Subtitle: If any one is near zero, the whole is zero.
- Prism: 3 · three parallel scales, multiplied
- Scheme:
  - key 1: Contact with uniqueness, 0–10: a living contact with what is theirs, not an idea about it
  - key 2: Resolve, 0–10: what they already put on the line for the new
  - key 3: Readiness to receive, 0–10: gifts land, resistance clears fast
  - key 4: "not yet" zone at the low end of every scale; formula contact × resolve × readiness
- Notes: no example numbers on the card (Sasha 2026-11-17). Threshold value is a hypothesis, not yet calibrated. Money sets the form of payment, not entry (kept off the card).
- Tags: guide · product · public
- Status: draft v6 · File: [book/laws/III.01.png](book/laws/III.01.png)

### III.02 · Which Program to Offer
- Context: Choosing a program · The hero's journey
- Subtitle: Where is the person on their hero's journey?
- Prism: 3 · three consecutive stages, a micro-quiz
- Scheme:
  - key 1: "Still in the old world?" → The Crossing
  - key 2: "Sees the new, not living it yet?" → The Vector
  - key 3: "Living it, ready to build?" → Build (working name; real program name open)
- Notes: for guides. Sasha: "cross" alone is unclear; the trajectory is entering the new world with depth on the hero's journey.
- Tags: guide · module · public
- Status: draft v6 · File: [book/laws/III.02.png](book/laws/III.02.png)

### VI.01 · Their Own 0–10 Scale
- Context: Coaching results · Measuring the shift
- Subtitle: The client rates each of their goals: at the start, the middle and the end.
- Prism: 3 · three goals × before → after
- Scheme:
  - key 1: goal in the client's own words (quote)
  - key 2: slider 0–10 with start mark and current value
  - key 3: "3 → 8" readout
- Notes: placeholder goals, no numbers on the card (no client data, no dummy figures).
- Tags: guide · product · public
- Status: draft v6 · File: [book/laws/VI.01.png](book/laws/VI.01.png)

### VI.02 · Compared to What You Expected
- Context: Coaching results · Measuring the shift
- Subtitle: At the end, one question for each goal: "How far did it come true?"
- Prism: 5 · scale −2 … +2
- Scheme:
  - key −2: much less · −1: less · 0: as I expected · +1: more · +2: much more
- Notes: the expectations scale Evolver proposed for coaching (2026-11-17), adapted from goal attainment scaling. Only this scale on the card (Sasha 2026-11-17).
- Tags: guide · product · public
- Status: draft v6 · File: [book/laws/VI.02.png](book/laws/VI.02.png)

### VI.03 · Seen Change Gets Paid Fairly
- Context: Coaching results · Fair exchange
- Subtitle: Show clients what moved, in their own words. Never ask them to price it.
- Prism: 2 · two poles, guide ⇄ client
- Scheme:
  - key 1: guide → client: their change, shown back
  - key 2: client → guide: money · referral · gratitude
- Notes: the client is never asked to price the result in money (standing rule).
- Tags: guide · product · public
- Status: draft v6 · File: [book/laws/VI.03.png](book/laws/VI.03.png)

### VII.01 · One Transformation, Three Forms
- Context: Our system · How it is built
- Subtitle: Each shift we deliver exists as a product, a game step and a software module.
- Prism: 3 · one centre, three faces
- Scheme:
  - centre: one shift
  - key 1: Product, you buy it
  - key 2: Game step, you live it
  - key 3: Module, the code runs it
- Notes: one key per shift keeps offer, code and game in sync (kept off the card).
- Tags: builder · game/product/module · public
- Status: draft v6 · File: [book/laws/VII.01.png](book/laws/VII.01.png)
