# Vision · Theory · Application

> *© 2026 Alexander Konstantinov · [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)*

The universal ontology lives in three layers that feed each other in one cycle:

**vision → theory → application → tested in practice → vision**

| Layer | File | What it holds |
|---|---|---|
| Vision | [universal_ontology.md](universal_ontology.md) | The ontology and cosmology of the universe: what is, and how it unfolds |
| Theory | [universal_ontology_formalization.md](universal_ontology_formalization.md) | The mathematics and physics, step by step, each claim with its register |
| Application | [phase_shift_technology_library.md](phase_shift_technology_library.md) | Technologies of phase-shifting built on the vision |

**Why three layers.** The vision is seen, not derived; it stays in its own words. The theory translates it into mathematics and physics without bending either. The application turns it into practice, and practice returns what works and what doesn't to the vision.

**How to read the theory.** Every step is typed (🧱 existing theorem · 🔗 existing pieces joined through the invariant · 🌱 new hypothesis · ⚖ postulate) and every claim registered ([E] established · [M] mapping · [P] postulate · [O] open). A mapping is a correspondence, not a proof.

**Naming.** None of these files calls itself a theory of everything. That name is earned when the theory predicts something that can be checked.
