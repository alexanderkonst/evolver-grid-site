## 📋 Workflow для каждого модуля

1. **Открой NotebookLM** → notebooklm.google.com
2. **Create New Notebook**
3. **Загрузи source:**
   - Либо перетащи .txt файл из `notebooklm_sources/`
   - Либо скопируй текст из `transformation_modules_extended.md`
4. **Generate Audio Overview** (кнопка справа)
5. **Скачай MP3**
6. **Загрузи на YouTube** с названием: `[ID] Title` (например: "S4 Conscious Breath")
7. **Скопируй YouTube URL** → сохрани в таблицу
